## Using with AI Agents

This node is `usableAsTool: true`. When invoked from an AI/agent workflow the node behaves identically to a manual workflow, **except**:

- **Passwords are fail-closed.** Any field marked as a secret (e.g. `revealPlaintext`) is ignored when the node is running as a tool — plaintext secrets are never returned to an AI agent regardless of field values.
- Agents can create, update, rotate, and delete records normally.
- Safe agent prompt example: *"Find the password named X in org Y"*
